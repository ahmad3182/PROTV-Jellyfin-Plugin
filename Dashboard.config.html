Jellyfin home page tab

Adds a PROTV tab next to Favorites on the Jellyfin home page, listing every channel this tuner serves with the same numbering and names Live TV uses. The tab is drawn by the Custom Tabs plugin, so Plugin Pages, File Transformation and Custom Tabs all have to be installed and running.

Films and series (VOD)

Builds a real Jellyfin library (PROTV VOD) out of the PROTV film and series catalogue, so films and episodes play in every Jellyfin app, not only in the web browser. Every film and episode becomes a Jellyfin item whose stream is resolved from PROTV when it is played. The first sync writes the whole catalogue and can take a while; later runs only add what is new.
The slowest part of the first sync. Turn it off to keep only the metadata and streams, and add posters with a later sync.
Fetches the subtitle PROTV has for a film or an episode and stores it next to the stream, so Jellyfin offers it while playing. Skipped once the download limit below is reached.
How much the sync may download in total (posters, subtitles and the library icons). Once the limit is reached the catalogue is still mirrored, but nothing more is downloaded. 0 = no limit.
The address the library's streams point back at. Leave it empty to let PROTV ask Jellyfin for its own LAN address, which is right on almost every setup. Set it when clients reach this server through another name, for example http://jellyfin.lan:8096.
How often Jellyfin runs the VOD sync. Used the first time the task is created; change it later in Dashboard > Scheduled Tasks.

Diagnostics

Creates a report of versions, companion plugins, settings and recent errors to paste into a bug report. Passwords and secrets are never included, and IP addresses are shortened.
